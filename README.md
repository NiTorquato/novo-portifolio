## Como executar localmente

O projeto é estático e não precisa de instalação de dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/NiTorquato/novo-portifolio.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd novo-portifolio
   ```

3. Inicie um servidor local:

   ```bash
   python -m http.server 8000
   ```

4. Abra [http://localhost:8000](http://localhost:8000) no navegador.

Também é possível abrir `index.html` com a extensão Live Server do Visual Studio Code.
